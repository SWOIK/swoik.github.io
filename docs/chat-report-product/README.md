# ชุดเอกสารผลิตภัณฑ์ "รายงานแชทด้วย AI" (ชื่อชั่วคราว: ป้าเม้าท์)

ผลวิเคราะห์เว็บ whatbrandonthinks.com (อ่านหน้าสาธารณะเมื่อ 2026-11-19) และแผนต่อยอดสำหรับตลาดไทย
ตัวเลขและราคาทุกตัวเป็น **สมมติฐานที่ต้องพิสูจน์** ไม่ใช่ข้อเท็จจริงที่ยืนยันแล้ว

| ไฟล์ | เนื้อหา |
|---|---|
| [`01-prd-roadmap.md`](01-prd-roadmap.md) | PRD: ปัญหา, persona, ขอบเขตฟีเจอร์ (P0–P3), เมตริก, Roadmap 5 เฟส, ความเสี่ยง/PDPA |
| [`02-architecture-and-llm-cost.md`](02-architecture-and-llm-cost.md) | สถาปัตยกรรม, pipeline แบบ staged, parser, โมเดลข้อมูล, API, ต้นทุน LLM ต่อรายงาน |
| [`03-thai-pricing.md`](03-thai-pricing.md) | โครงสร้างราคา (บาท), จุดคุ้มทุน, วิธีชำระเงิน, แผนทดสอบราคา |
| [`cost_model.py`](cost_model.py) | สคริปต์คำนวณต้นทุน/จุดคุ้มทุน แก้ค่าใน ASSUMPTIONS แล้วรัน `python3 cost_model.py` |

Landing page ต้นแบบ: [`src/pages/chat-report/index.astro`](../../src/pages/chat-report/index.astro)
เปิดดูด้วย `npm run dev` แล้วไปที่ `/chat-report/` (หน้านี้ตั้ง `noindex` และไม่เก็บข้อมูลผู้ใช้)

## ข้อควรรู้
- ห้ามคัดลอกชื่อ/ตัวละคร/ข้อความ/รีวิวของคู่แข่ง ใช้เพียงแนวคิดระดับผลิตภัณฑ์
- ก่อนเปิดจริงต้องผ่าน: ตรวจเครื่องหมายการค้า, ทนาย PDPA, นักบัญชี (VAT/ใบกำกับ), ทดสอบ safety กับแชทสมมติ
- `npm run build` ในสภาพแวดล้อมที่บล็อกเครือข่ายภายนอกอาจล้มที่ขั้นสร้างภาพ OG เดิมของธีม AstroPaper (ดาวน์โหลดฟอนต์จาก 1001fonts.com) ซึ่งไม่เกี่ยวกับหน้าใหม่
